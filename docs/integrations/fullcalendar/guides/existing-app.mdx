---
title: Existing App
description: Step-by-step guide for adding FullCalendar WebMCP to an existing FullCalendar React setup without modifying your UI or backend architecture.
---

If you already have a working React application with FullCalendar, adding FullCalendar WebMCP takes only a few minutes.

The integration is designed to adapt to your application—not the other way around.

## What to keep unchanged

- **Your FullCalendar options:** Plugins (dayGrid, timeGrid, list, interaction), header toolbars, custom date click handlers, and event content renderers remain exactly as they are.
- **Your backend and database:** Keep your existing API endpoints, database tables, and authentication checks. See the [Persistence Model](/integrations/fullcalendar/concepts/persistence).
- **Your state management:** Keep your React state, React Query / SWR hooks, or Redux store.

## Step-by-step integration

### 1. Install the package

```package-install
npm install @protocoltooling/fullcalendar
```

### 2. Wrap your existing API in CalendarEventRepository

Create an adapter that delegates to your existing API service or data fetching functions:

```ts services/calendar-adapter.ts
import type { CalendarEventRepository } from "@protocoltooling/fullcalendar";
import * as api from "./events-api";

export const calendarRepository: CalendarEventRepository = {
  async list(query) {
    return api.fetchEvents(query);
  },
  async get(id) {
    return api.fetchEventById(id);
  },
  async create(input) {
    return api.createEvent(input);
  },
  async update(id, input) {
    return api.updateEvent(id, input);
  },
  async delete(id) {
    await api.deleteEvent(id);
  },
};
```

### 3. Add calendarRef and call the hook

In your calendar component:
1. Create a `calendarRef` with `useRef`.
2. Pass `calendarRef` to `<FullCalendar ref={calendarRef} ... />`.
3. Call [`useFullCalendarWebMCP`](/integrations/fullcalendar/reference/use-fullcalendar-webmcp) with your repository and your existing data refetch function.

```tsx components/CalendarView.tsx
import FullCalendar from "@fullcalendar/react";
import dayGridPlugin from "@fullcalendar/daygrid";
import timeGridPlugin from "@fullcalendar/timegrid";
import interactionPlugin from "@fullcalendar/interaction";
import { useCallback, useRef, useState, useEffect } from "react";
import { useFullCalendarWebMCP, type CalendarEvent } from "@protocoltooling/fullcalendar";
import { calendarRepository } from "../services/calendar-adapter";

export function CalendarView() {
  const calendarRef = useRef<FullCalendar>(null);
  const [events, setEvents] = useState<CalendarEvent[]>([]);

  // Your existing fetch function
  const refreshData = useCallback(async () => {
    const data = await calendarRepository.list();
    setEvents(data);
  }, []);

  useEffect(() => {
    void refreshData();
  }, [refreshData]);

  // Connect WebMCP tools
  useFullCalendarWebMCP({
    calendarRef,
    events: calendarRepository,
    onEventsChanged: refreshData,
  });

  return (
    <FullCalendar
      ref={calendarRef}
      plugins={[dayGridPlugin, timeGridPlugin, interactionPlugin]}
      initialView="dayGridMonth"
      events={events.map((e) => ({ ...e, end: e.end ?? undefined }))}
      editable={true}
      selectable={true}
      // Your existing event click / drag handlers work as normal
    />
  );
}
```

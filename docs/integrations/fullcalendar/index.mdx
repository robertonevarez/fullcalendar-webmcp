**FullCalendar WebMCP** is an integration published by **Protocol Tooling** that makes FullCalendar React applications agent-ready using WebMCP.

It registers standard calendar tools on the browser's model context while leaving your existing persistence, backend, database, and state management in control.

## What is it?

FullCalendar WebMCP is a React integration that connects FullCalendar to WebMCP (Web Model Context Protocol). AI agents running in WebMCP-capable browsers can query views, list events, and perform calendar mutations through your existing application.

FullCalendar WebMCP is published as `@protocoltooling/fullcalendar`:

```package-install
npm install @protocoltooling/fullcalendar
```

## Who publishes it?

FullCalendar WebMCP is built and published by **Protocol Tooling** as part of its suite of agent interfaces for existing web software.

## What does it change?

You add one React hook—[`useFullCalendarWebMCP`](/integrations/fullcalendar/reference/use-fullcalendar-webmcp)—and connect it to your existing event operations via a [`CalendarEventRepository`](/integrations/fullcalendar/reference/calendar-event-repository) adapter object.

```tsx
import { useRef } from "react";
import FullCalendar from "@fullcalendar/react";
import { useFullCalendarWebMCP } from "@protocoltooling/fullcalendar";

export function CalendarView() {
  const calendarRef = useRef<FullCalendar>(null);

  useFullCalendarWebMCP({
    calendarRef,
    events: eventRepository,
    onEventsChanged: refetchEvents,
  });

  return (
    <FullCalendar
      ref={calendarRef}
      events={events.map((e) => ({ ...e, end: e.end ?? undefined }))}
    />
  );
}
```

## What does it not change?

The FullCalendar WebMCP integration does not replace your backend or database:

- **Keep your FullCalendar setup:** Use your existing plugins, custom views, themes, and event renderers.
- **Keep your backend & database:** FullCalendar WebMCP does not store events. Your API or database remains the single source of truth. See the [Persistence Model](/integrations/fullcalendar/concepts/persistence).
- **Keep your state management:** Human interactions and AI agent actions converge on the same persistence layer and trigger your existing data refresh logic.

Add a WebMCP interface to an existing FullCalendar React application—without replacing your backend, database, state management, or FullCalendar setup.

```package-install
npm install @protocoltooling/fullcalendar
```

## How it fits your app

You keep ownership of event persistence. The integration registers calendar tools in the browser and routes agent reads and writes through your existing operations:

```ts
useFullCalendarWebMCP({
  calendarRef,
  events: repository, // your list / get / create / update / delete
  onEventsChanged: refreshEvents,
});
```

```text
Agent ⇄ WebMCP tools ⇄ your repository ⇄ your DB / API / state
                              ↓
                       onEventsChanged
                              ↓
                         FullCalendar
```

Your app remains the source of truth. FullCalendar WebMCP never becomes a second event ledger.

## What you get

Six tools agents can call:

- `calendar_get_context`
- `calendar_list_events`
- `calendar_get_event`
- `calendar_create_event`
- `calendar_update_event`
- `calendar_delete_event`

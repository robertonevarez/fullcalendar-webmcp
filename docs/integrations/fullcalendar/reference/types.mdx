## `CalendarEvent`

Core event model returned by your repository and by list/get tools.

```ts
export interface CalendarEvent {
  id: string;
  title: string;
  start: string;
  end: string | null;
  allDay: boolean;
  /** Optional host-selected, JSON-safe, agent-visible projection. */
  metadata?: JsonObject;
}
```

Add `metadata` when agents need context beyond the core fields. You choose exactly what is exposed. Metadata is **read-only** through WebMCP writes. Protocol Tooling never exposes FullCalendar `extendedProps` automatically.

## `JsonObject` / `JsonValue` / `JsonPrimitive`

JSON-safe types for agent-visible metadata.

```ts
export type JsonPrimitive = string | number | boolean | null;
export type JsonValue =
  | JsonPrimitive
  | JsonValue[]
  | { [key: string]: JsonValue };
export type JsonObject = { [key: string]: JsonValue };
```

## `FullCalendarHandle`

Minimal structural surface required by FullCalendar WebMCP from a FullCalendar React instance. Compatible with FullCalendar React v6 class instances and v7 `CalendarRef` handles.

```ts
export interface FullCalendarHandle {
  getApi(): {
    getOption(name: string): unknown;
    view: {
      type: string;
      activeStart: Date;
      activeEnd: Date;
    };
  };
}
```

## `FullCalendarWebMCPOptions`

Configuration options passed to [`useFullCalendarWebMCP`](/integrations/fullcalendar/reference/use-fullcalendar-webmcp).

```ts
import type { RefObject } from "react";

export interface FullCalendarWebMCPOptions {
  calendarRef: RefObject<FullCalendarHandle | null>;
  events: CalendarEventRepository;
  onEventsChanged: () => unknown | Promise<unknown>;
  capabilities?: FullCalendarWebMCPCapabilities;
  onRegistrationError?: (error: unknown) => void;
}
```

```ts
export interface FullCalendarWebMCPCapabilities {
  read?: boolean;
  create?: boolean;
  update?: boolean;
  delete?: boolean;
}
```

For more details on implementing these interfaces, see [`CalendarEventRepository`](/integrations/fullcalendar/reference/calendar-event-repository), the [Repository Contract](/integrations/fullcalendar/concepts/repository), and [Security](/integrations/fullcalendar/concepts/security).

The `@protocoltooling/fullcalendar` package exports the following TypeScript interfaces and types for the FullCalendar WebMCP integration.

```ts
import type {
  CalendarEvent,
  CreateCalendarEventInput,
  UpdateCalendarEventInput,
  CalendarEventQuery,
  CalendarEventRepository,
  FullCalendarHandle,
  FullCalendarWebMCPOptions,
  JsonObject,
  JsonPrimitive,
  JsonValue,
} from "@protocoltooling/fullcalendar";
```

---

## `CalendarEvent`

Normalized calendar event model.

```ts
export interface CalendarEvent {
  id: string;
  title: string;
  start: string;
  end: string | null;
  allDay: boolean;
  /** Experimental (unreleased): optional host-selected, JSON-safe, agent-visible projection. */
  metadata?: JsonObject;
}
```

> **Experiment note:** `metadata` is proposed on an unreleased branch. Published `@protocoltooling/fullcalendar@0.1.1` does **not** include this field. Metadata is explicitly selected by the host repository — Protocol Tooling does **not** automatically expose FullCalendar `extendedProps`. Metadata is **read-only** at the WebMCP write boundary.

## `JsonObject` / `JsonValue` / `JsonPrimitive`

Experimental JSON-safe types for agent-visible metadata.

```ts
export type JsonPrimitive = string | number | boolean | null;
export type JsonValue =
  | JsonPrimitive
  | JsonValue[]
  | { [key: string]: JsonValue };
export type JsonObject = { [key: string]: JsonValue };
```

## `FullCalendarHandle`

Minimal structural surface required by FullCalendar WebMCP from a FullCalendar React instance. Compatible with FullCalendar React v6 class instances and v7 `CalendarRef` handles.

```ts
export interface FullCalendarHandle {
  getApi(): {
    getOption(name: string): unknown;
    view: {
      type: string;
      activeStart: Date;
      activeEnd: Date;
    };
  };
}
```

## `FullCalendarWebMCPOptions`

Configuration options passed to [`useFullCalendarWebMCP`](/integrations/fullcalendar/reference/use-fullcalendar-webmcp).

```ts
import type { RefObject } from "react";

export interface FullCalendarWebMCPOptions {
  calendarRef: RefObject<FullCalendarHandle | null>;
  events: CalendarEventRepository;
  onEventsChanged: () => unknown | Promise<unknown>;
  onRegistrationError?: (error: unknown) => void;
}
```

For more details on implementing these interfaces, see [`CalendarEventRepository`](/integrations/fullcalendar/reference/calendar-event-repository) and the [Repository Contract](/integrations/fullcalendar/concepts/repository).
